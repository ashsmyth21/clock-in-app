Slack Settings
Configure your Slack App bot token and channel IDs per team
Step 1 — Create a Slack App & get a Bot Token
  1. Go to api.slack.com/apps and click Create New App → From scratch.
  2. Name it (e.g. Staff Clock-In) and pick your workspace.
  3. Under OAuth & Permissions → Bot Token Scopes, add chat:write.
  4. Click Install to Workspace and authorise it.
  5. Copy the Bot User OAuth Token (starts xoxb-…).
  6. In PythonAnywhere: Web tab → Environment variables — add SLACK_BOT_TOKEN with that value, then Reload the app.
  7. Invite the bot to each team channel: type /invite @Staff Clock-In in the channel.
Step 2 — Enter channel IDs below

To find a channel ID: right-click the channel name in Slack → View channel details → scroll to the bottom. It looks like C0123ABCDEF. Leave a field blank to disable notifications for that team.
